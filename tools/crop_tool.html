使用說明、限制與技術來源

1. 選圖 → 2. 設定切割寬高 → 3. 輸入中心座標或直接點擊／拖曳 → 4. 查看結果 → 5. 裁切並下載。

  • 預設保留你指定的輸出大小；超出原圖的區域填入透明或背景色。自動移回模式不改變大小；切割區比原圖大時，需縮小切割區才能下載。
  • 無勾選「換圖時保留切割設定」時，換圖會置中並將過大的切割區縮小至圖內。勾選時保留大小、中心及比例設定。
  • 所有內容在本機處理，不上傳圖片，不需安裝 Python 或連網。使用新版 Chrome、Edge、Firefox 或 Safari。
  • 支援瀏覽器可解碼的 PNG、JPG、WebP、GIF、BMP、AVIF；動畫僅取靜態影格。輸出不保留原圖 EXIF、DPI 與原 ICC 設定。
  • 原圖及輸出最多 3,200 萬像素，單邊最多 16,384 px；原檔最多 50 MiB。可用尺寸也受裝置記憶體限制。
  • PNG 無損並支援透明；JPG 的透明部分使用背景色。品質滑桿只作用於 JPG／WebP。預覽反映裁切與背景；有損編碼的細節請以下載檔為準。
  • 檔案下載位置由瀏覽器設定決定。每次下載均從原圖取出，不會累積縮放誤差。

官方來源：Canvas drawImage、toBlob、Pointer Capture、ResizeObserver。
