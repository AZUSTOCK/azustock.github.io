操作、JSON 格式、動畫擴充與技術來源

程式碼區可直接編輯完整的 <svg>…</svg>。按「套用程式碼」才會更新文件；有未套用的修改時，繪圖與其他文件操作暫停，避免覆蓋你的程式碼。格式有錯時保留原畫面，修正後可再套用。「還原為目前畫面」會捨棄未套用的修改。

畫布背景、中心軸、控制點與選取效果都是編輯器介面，不會匯出。透明 SVG 嵌入不同底色時可能呈現不同觀感；需要實際背景時，請在 SVG 中加入背景矩形。畫完後維持目前的繪圖工具；切換工具會自動關閉選取編輯。「選取編輯」按鈕開啟時可選取、移動與修改節點；關閉時回到原本的工具，不需重選。拖曳預覽框與選取框都會顯示中心「＋」。中心軸與方格線可個別顯示，並調整格距、虛線樣式、顏色與透明度；它們只存在於介面，不會匯出。點擊圖形或使用「圖形清單」，可選取群組及群組內的個別圖形；拖曳本體移動，拖曳控制點調整形狀。位移、縮放、旋轉與線色、線寬、填色、透明度都可在介面修改。

JSON 專案有版本號：schema、version、document（SVG 節點樹）、animation、extensions，以及由文件產生的 svg 字串。直接提取文字：

const project = JSON.parse(jsonText);
const svgText = project.svg;
document.getElementById('svg-container').innerHTML = svgText;

使用本工具匯出且驗證過的內容。HTML 嵌入範例會將 JSON 放入 application/json 區塊並處理特殊字元；也可直接複製 SVG 標記放入 HTML。專案 JSON 的 watermark_url 是 SVG Data URL，可直接用於 CSS url()；它與 svg 由同一份文件產生。匯出「浮水印 JSON」則只包含 watermark_url 欄位。

多選：開啟選取編輯後，Shift／Ctrl／Cmd＋點擊可加入或取消選取；在空白處拖曳可框選，搭配上述按鍵則追加框選。Ctrl／Cmd＋A 選取全部。拖曳已選圖形可一起移動；多選框角點可縮放，綠色控制點可旋轉。外觀工具列可一起改色、線寬與透明度，Delete 或「刪除圖形」可一起刪除。群組與其中的子圖形不會同時納入選取，避免重複變換。

從節點起筆：關閉「選取編輯」，選擇直線或貝茲，按住綠色節點拖出新線；也能在節點附近起筆，終點接近其他節點時會吸附並顯示橘色圓環。Alt 可暫時取消吸附；Shift 的直線軸向限制優先於吸附。開啟編輯模式後，節點拖曳會移動共用節點並同步相連線條，不會新增線條。從節點起筆、或終點吸附到既有節點時，會共用同一個節點 ID；拖動節點或圖形時，相連線段會同步修改，包含貝茲端點與相鄰控制柄。線端帶動矩形／圓的連結節點時，圖形會整體平移；直接拖圖形尺寸控制點則調整尺寸。JSON 專案保留共用節點 ID。舊檔未記錄 ID 時，編輯節點會辨識同位置的節點並建立連結。Alt 起筆／落筆可保留獨立節點。大量節點最多顯示 2,000 個起筆點；大型畫布會放大輔助線格距以維持操作順暢。

貝茲操作：選「貝茲曲線」後由任意起點拖到終點；開啟「選取編輯」後，拖橘色控制柄調整彎曲，拖藍色節點改位置。直線也從按下的位置開始，不會吸附中心軸。矩形、橢圓與正圓以拖曳的範圍繪製。選取模式雙擊線條可新增節點；新增時將 C／Q 曲線分段，保留曲線形狀。點選藍色節點後按 Delete 或「刪除節點」；刪除會重新連接相鄰段。可用「節點前段」切換直線、三次或二次貝茲。直線、相對座標、H／V、C／S、Q／T 的單一子路徑可視覺編輯；編輯時轉成等效絕對座標。A 圓弧與多子路徑保留原文，可整體移動與在程式碼中修改。

相容你原本的浮水印讀取方式：匯出「浮水印 JSON」，或從完整專案 JSON 讀取相同欄位。URL 已編碼，包含引號、#、中文等 SVG 內容也能使用。

const cat = JSON.parse(jsonText); // 或將此欄位合併到原本的 cat
const watermarkStyle = cat.watermark_url ? ` style="--custom-watermark: url('${cat.watermark_url}');"` : '';
// 將 watermarkStyle 放進原本 HTML 的起始標籤。
// 顯示浮水印的 CSS 需使用 background-image: var(--custom-watermark);

動畫目前可從程式碼使用 animate、animateTransform、animateMotion、set，或 SVG 內的 CSS keyframes。播放／歸零／時間控制針對原生 SMIL；CSS 動畫會保留，但不受此控制。繪圖操作前會將 SMIL 歸零並暫停。匯出保留動畫定義，不會截取成靜態影格。

架構分為 SvgCodec（解析／驗證／序列化）、ProjectStore（文件與歷史）、SceneView（預覽／控制點）、DrawingController、CodePanel、AnimationController 與 ExportService。animation.tracks、extensions 供未來關鍵影格編輯器或其他模組擴充，目前僅保留資料，未實作 tracks 播放引擎。手繪的編輯變換保存在文件節點的 editor.matrix，匯出時轉成外層 g transform，保留內部原始路徑、ID 與動畫。視覺變換會新增外層 g，CSS 若使用 svg > rect 等直接子元素選擇器會受結構影響，建議使用圖形 ID 或 class 選擇器。

  • 可匯入曲線、群組、文字、漸層、濾鏡、遮罩、裁切、內部引用及上述動畫。拒絕腳本、事件屬性、foreignObject、外部資源與 DTD；圖片可使用內嵌 PNG／JPG／WebP Data URL。預覽樣式隔離於 Shadow DOM。
  • 單次文字／檔案最多 2 MiB、文件最多 5,000 節點、巢狀最多 64 層。歷史最多 60 筆並設記憶體上限。一般繪圖座標保留三位小數；連結節點與變換匯出保留六位小數，減少跨座標系的誤差。
  • SVG／JSON 檔案與 HTML 範例均為純文字，可離線處理。不需 Python 或外部套件；不會將內容上傳。
  • JSON 同時提供 document 與 svg 時，兩者須一致；通常請在 SVG 分頁改圖，在 JSON 分頁改 animation／extensions。FPS 目前為專案設定，原生 SMIL 的畫面更新頻率由瀏覽器處理。完整關鍵影格時間軸尚未提供。
