讓你畫的 SVG 動起來

先看效果，再複製到工具。每個範例都從暫停開始，按播放才會動；程式碼只使用原生 SVG SMIL。

在工具內操作
  1. 先匯出 JSON 備份目前作品。
  2. 複製一個完整 SVG → 貼入「SVG 程式碼」→ 按「套用程式碼」。完整範例會替換目前圖形。
  3. 按畫布下方「播放」。拖曳時間滑桿查看影格；按「歸零」回到起點。
  4. 匯出 SVG 保留動畫，匯出 JSON 保留編輯資料。
也能直接按工具的「動畫範例」按鈕，再套用與播放。完整細節、網頁與浮水印程式在範例包的 README.md。

修改你自己的圖形

找到 circle／rect／path，將自閉合 /> 改成 >，把 animate 放進去，再補上結尾標籤。保留原本的顏色、尺寸和外層變換。

設定用途
attributeNamecx／cy：圓的位置；x／y：矩形的位置；opacity：透明度；d：曲線形狀。
values="-180;180;-180"起點 → 中點狀態 → 終點狀態。
dur="4s"一輪 4 秒；改成 8s 就慢一倍。
repeatCount="indefinite"持續循環。只播一次可設 1，再加 fill="freeze" 保留最後狀態。

控制項與共用節點

工具的「範圍」只設定時間滑桿上限，速度由 SVG 的 dur 決定。「FPS」目前只保存設定，沒有影片／GIF 匯出。SVG 內 CSS 動畫不受工具的 SMIL 時間控制。

編輯時拖動共用節點會修改相連線條；動畫播放時不會逐影格執行這個連動。整組運動請用群組；固定兩端、移動接點請參考最後一個同步曲線範例。

下載 HTML 後直接以瀏覽器開啟即可，無外部套件。此頁的 JavaScript 只控制預覽；複製和下載的 SVG 本身不含 script。
