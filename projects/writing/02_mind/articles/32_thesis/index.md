# 「正論怪物」
我們就從別人跟我說的話開始。  
她說「不管讀什麼都會失業，那不如讀自己喜歡的科系。」  
這句話有兩個重點：  
<br/>
第一是「失業」。默認了讀書的目的性為就業，然而這個單箭頭並非充分的，並且或許有其必要性。意即讀書不一定能找到工作、但是不讀書找不到工作。(此處的工作係指刻板印象中，狹義的對於賺錢的工作的理解)   
<br/>
第二是「自己喜歡的」。此處讓讀書有了有別於「功利」、「謀生」等客觀為導向的價值，即為主觀自我價值。也就是說，讀書從單方面的給予你社會價值，變為你單方面的賦予讀書意義，兩著的出發點並不相同。  
<br/>  
認識完兩者的差異後，我們回來看LLM。  
LLM是本世紀的工業革命，當初的工業革命讓生產速度上升、品質一致性上升、職缺趨勢改變等等。你會看到傳統勞工被開除、技術職缺增加、新的技術推陳出新等等。  
每一項工業進步，都代表著後人踩在前人的或溫熱、或面目全非的屍體上，讓科技得以越疊越高。  
所以工業上很正常的趨向「創新」，當然，商業也是如此。  
<br/>
好了，這樣說來，好像LLM的發展有點道理，所以裁員、生活型態改變是很正常的。  
我的結論為「是。」  

所以我就被自然而然的汰換，又或是說取代掉了。  
我的結論為「是。」  

那這樣子我就失業了！我就沒有錢了！我就被踢出局了！  
我明明付出了那麼多的努力！  
<br/>
你當然會生氣，因為這觸及了你的「利益」，但是本質上沒有任何改變。  
當然，你會覺得我在亂講話，因為我在解釋那個傷害著你的那一方。  
但是如果換成這些呢？  
<br/>
請問你上班會騎馬去嗎？  
請問你的衣服是買的還是自己織的？  
請問你會用電報聯絡他人還是用網路、用電話？  
請問你會不會詛咒那個成功坐到了別人位置的自己？  
<br/>
承Linus吉言：「這只是另一種工具。我們使用工具已經幾十年了。我們以前寫機器碼，然後有了組譯器，然後有了編譯器，而 AI 只是另一個層級的工具。」  
<br/>
替代從古至今是無可避免的，所以這不是LLM產生的問題，LLM只是跟當年的工業機器一樣，被當作靶子而已，畢竟你還是要找個發洩口，不論是上司或是那套系統。  
<br/>
講到這裡，大概有人看不下去了。「我看LLM不爽，這個人怎麼一直在幫LLM說話(生氣臉)」  
<br/>
所以，在同意科技發展的同時，我們要來看看工業革命下的另一個面向，也就是  
——「對行為的批判。」  
<br/>  
工業革命的開始，手工被批判成了貧窮、落後、雜亂的象徵。這跟現在很像，不使用AI的人在論壇上被笑、被譏諷。  
但是在工業革命後的手工興起了新的意識，那就是「文化與美學」的象徵，以抵抗工業思想價值。  
而這是一個新的高度。手工因為被取代了，因此才被人們賦予了新的價值。  
而這也是現在很悲哀的一點。  
因為在LLM當道的當下，現代的反對者卻仍然固著於「工業性」思維。  
<br/>
以繪畫為例，大家關心的無非就是工作、版權、使用LLM與否而已。  
這些除了很表面以外，還很無知的以為畫畫是以結果為導向，這是對於繪畫這件事的降格。  
明明表面上是在支持繪畫，字裡行間中卻充斥著的對於繪畫價值的自我侷限。  
<br/>
也因此，這是我討厭LLM的原因、這是我討厭現今社會的原因  
——「結果導向的世界。」  
<br/>  
回到最前面的那句話：「自己喜歡的」  
這與我在[〈創作〉](?p=mind&a=create)那篇寫的觀點一致，那就是「內源性的驅動力。」  
那才是真正的價值所在，而非產品的成功與否。  
<br/>
創作的目的是為了自己情感的抒發、自己的分享欲、自己的想要，重要的是自己。  
這也是為什麼一個畫作會在旁寫上作者的名字與經歷，但是一顆飯糰卻只在標籤上寫下商品名與成分表。  
因為前者，我們看的是作者是怎麼一步一步走到現在，讓我們得以看見眼前的畫作。但是後者我們只在乎它品質好不好。  
前者是作者的經歷、後者是公司產品的把控。  
<br/>
因此，LLM給了我們一個很好的機會，來做一次自我的審視。  
來看看你到底將創作降格成了產品製造，還是仍然認知到那是個過程。  
<br/>  
所以我不討厭LLM，但是我討厭用LLM做出產品、用LLM跳過自我以及用LLM用出傲慢，然後還大肆宣揚的人，  
那些只是可以被取代的機器。  
<br/>
而即使你沒有創作，僅僅只是過完你的一生，都不會淪落到成為了機器而自滿。
