# 「舉手」
少女不想引人注目，  
不過，有天能回答老師的問題也不錯！  
<br/>
於是少女在老師詢問時都嘗試的舉起了手，可是每次都沒有被點到。  
看到老師都不點自己，少女想：「下次如果再高一點，會不會就被點到了！」  
<br/>
於是少女在老師詢問時都踴躍的舉起了手，可是每次都沒有被點到。  
看到老師都不點自己，少女想：「下次如果再快一點，會不會就被點到了！」  
<br/>
於是少女在老師詢問時都迅速的舉起了手，可是每次都沒有被點到。  
看到老師都不點自己，少女想：「下次如果再會一點，會不會就被點到了？」  
<br/>
於是少女在老師詢問時都自信的舉起了手，可是每次都沒有被點到。  
看到老師都不點自己，少女想：「下次如果再難一點，會不會就被點到了？」  
<br/>
於是少女在老師詢問時都肯定的舉起了手，可是每次都沒有被點到。  
看到老師都不點自己，少女有一點沮喪。  
明明自己已經那麼努力了，但是老師都點其他人。  
於是少女去找老師問了，老師說：  
<br/>
「也許是碰巧沒有點到吧！」  
<br/>  
於是少女在老師詢問時都隨興的舉起了手，可是每次都沒有被點到。  
看到老師都不點自己，少女想：「下次如果再少一點，會不會就被點到了。」  
<br/>
「但是還是會有人舉手的吧。」
