# 放學後
<div class="vertical-wrapper">

要達成某項成就，就必須要有相對應的付出。  
就好比繪畫，首先要有紙張跟筆。一開始可以用鉛筆，然後畫在課本的空白處。如果要上色的話就不一樣了，什麼品牌的畫筆適合什麼樣的筆觸、什麼樣的畫具適合什麼樣的紙、什麼樣的色彩適合什麼樣的呈現等等，都還需要取自己去研究跟花費一些零用錢，而這都還沒算上練習所花的時間。  

但是時間是很寶貴的。  
一個人的財富、閱歷可以無限的增加，但是唯獨時間，只會越來越少。  
而年紀也是如此。  
幼兒的時候、青少年的時候、出社會的時候、成家的時候，能做的、該做的事情都不一樣。  
時間要花在哪裡變成了一個顯學。總是有人說「時間要花在對的地方」這種冠冕堂皇的大道理。而往往會這樣想的人都把時間用在錯誤的地方，例如花在思考這句話。  
不過我不一樣，我會把時間花在最重要的事情身上！  

我可是女高中生呢。  
<br/>

---

雖然跟夜中同學約好從今天開始由她幫我補習，但是仔細想一想，我這樣不是跟原來一樣嗎？  
只是從在補習班補習變成在教室補習，根本沒有差別嘛！而且還讓夜中同學被迫跟我一起留下來。  
『我到底在幹嘛阿？』  
一邊想著這些事情，順便穿插著因為炎熱而產生的牢騷，時間已經到放學了。教室一如既往地只剩我和夜中同學兩人。  
『平常大家也那麼快回家嗎？』我有些好奇，不過以前我都是在回家火車的前列（但是是去補習），應該是沒有看過吧。  
不過這種天氣，校門口前的冰店總是大排長龍。因為是移動攤販，為了吃冰而先離開教室的人佔了多數，應該稱作吃冰列車比較正確，不然大家應該都會在教室聊天吧？我如此的猜測。  
<br/>  
「那，開始上課吧。」夜中同學的聲音聽起來低沉又帶著很高的共鳴。她應該是在學國文老師吧。  
「是，請多指教」我用一個高亢的聲音回道。這是數學老師的聲音。  
我看向了她，她今天有戴眼鏡阿，看起來很有正經的書蟲的感覺。不是說眼鏡會限制一個人的樣貌嗎？但是反過來，戴上眼鏡就會突然有種她很聰明的感覺。不過夜中同學的成績確實很好，校排名都是第一坐收，也難怪她會亂拉人出去玩。  
「請翻開講義第1...」她笑了出來。  
我也跟著笑了，看起來學兩個夫妻說話讓她沒辦法裝正經了。  
笑了一陣子後，普通的補習開始了。  
<br/>  
教學，寫題目，訂正，提問，解答......  
夜中同學提出的題目都剛好在我的誤區裡，我可能是被誤導，又或是漏了某項重點，夜中同學都幫我找了出來。  
我清晰的了解到團體補習班與個人家教的差異。我開始有種把補習費給夜中同學請她當家教的衝動，不過家教應該更貴吧？畢竟是一對一，沒有人能一起分攤。  
<br/>
「這題就這樣，今天就到這裡吧！」  
感覺今天學的東西可以抵兩堂，不對，應該是三堂補習班的影片。我對夜中同學的敬畏又增加了幾分。  
「好想吃冰~戶賀同學呢？」夜中同學攤在椅子上，看著天花板。  
「我也要吃。」經過了強力運轉的我的大腦對於糖分的渴望，成功的被夜中同學喚起了，突然出現的疲憊感是這麼告訴我的。  
「戶賀同學要休息嗎？」夜中同學伸了個懶腰，頭歪向了我。  
「我想應該不用，總而言之先吃冰吧。」雖然這麼說，但是我趴在桌上，好像沒什麼說服力。  
「那我去幫妳買吧。薄荷巧克力可以嗎？」  
「誒，可以是可以，不過天氣那麼熱，夜中同學一個人拿會很麻煩吧？那我也一起去。」語畢，我準備抬起頭，卻發現我起不來。  
「疑？」我試著動一動我的腳，別說是動不了，我甚至沒有感受到它的存在。  
「妳就不要逞強了，我會幫你買的，從校門口到這裡也沒有很遠。」  
「再說了我第一次也是這樣的，無可動彈個十幾二十分鐘也是很正常的。戶賀同學先好好休息吧~」  
我目送著夜中同學離開，慢慢閉上了雙眼。  
<br/>  
等我醒來的時候，我的嘴裡塞了根冰棒。是外面有塑膠，需要轉開來食用的那種。明明這種冰棒很方便，融化後不會滴的身上黏黏的，是這種天氣的福音。但是附近只有校門口的冰店會賣，其他的不是挫冰就是中間有木條的冰棒。  
我成功的坐了起來，夜中同學不知去了哪裡。  
我把剩下的水吸完，試著動了動腳，確認有感覺之後起身去教室外的垃圾桶。 
 
「阿，妳醒了，身體還好嗎？」夜中同學從走廊走了過來。  
「現在可以動了，謝謝妳的冰棒。」我把管子丟入了垃圾桶。  
「不用謝，話說妳有想去的地方嗎？」夜中同學直直看著我。  
「現在？」時間不早了，夜中同學還想去玩嗎？雖然我請她補習是想讓自己在遊玩的時候，同時也有學習，但是這總歸是個臆想，畢竟我們花了很多時間在念書。  
不過，也不怪我有這種想法，畢竟手錶上的4:10是不會錯的。  
「我沒什麼想法呢，夜中同學決定吧。」  
「那，我們去那裡吧！」夜中同學的眼睛裡閃爍著光芒。  
<br/>  
我賭對了。
