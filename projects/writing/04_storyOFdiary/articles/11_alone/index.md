# 一個人
<div class="vertical-wrapper">

++[KEY:StoryOFDiary#11|SILENT]++
日記到底要寫什麼？  
寫一些抱怨來發洩情緒？  
寫一些紀錄來留下心情？  
寫一些想寫的東西就好？  
<br/>  
現在的話，感覺我寫的不是很像日記。  
明明日記應該是小小的、隨興的模型。  
可是我卻越寫越多字、想越來越多事。到最後，就好像在寫小作文一樣。  
每頁都密密麻麻的占滿了文字，我都沒有空間畫插畫了。  
雖然本來就不太會畫畫，可是看到空白的地方就會想要用什麼把它填滿，所以都用彩色的筆畫上一些線條。  
姊姊也是，雖然她的字都寫很少，但是空白處卻很少。因為都被五顏六色的紙膠帶貼滿了。  
果然紙張還是白白的地方越少越好！  
<br/>
所以字越寫越多、事情想的越來越多，感覺無時無刻都在想我要寫什麼。  
上次就差點要錯過火車了。  
作業也是，最近都到了死線還積了一堆，認真一點啊我自己！  
<br/>
趕快把作業寫完，週六還要跟大家去看電影！  
然後寫進日記裡！  

<br/>

---

<br/> 

好久沒有放學後自己一個人了。  
有里還是那樣顧慮很多呢，說什麼：「一直請假的話感覺很對不起付錢的父母。」所以去補習了。  
之前好像也是這樣，說自己要去補習，所以一直拒絕別人的邀請。  
可是我知道歐\~  
有里只是太正直了。她一定也不喜歡補習、一定也想出去玩，但是腦袋有點死板板的，就像是被責任感塞滿一樣，所以總是在擔心。  
可是這樣的生活，肯定會很辛苦的，而且又不快樂。  
還是要適時的過一下無憂無慮的生活呢！  
<br/>
所以，  
『明明讓我教就可以了！』  
有里也說我教的很好、考試也有顯著的進步，那就可以一起去玩了不是嗎？  
……  
<br/>
結果還是去補習了，還真是有里呢。  
<br/>  
而且今天碰巧大家都約好了，所以只能自己一個人遊蕩。  
不過我不喜歡這樣，沒有大家一起吵吵鬧鬧的話感覺會很無聊，乾脆就待在家裡好了。  
加入一次回家部也蠻新鮮的！  
<br/>    
我躺在了床上，眼睛也閉上了一段時間，不過完全沒有睡意。  
果然是因為還不累嗎？  
「要做什麼好呢？」不能提早睡著的話就來找些事情做！  
<br/>
櫃子裡有沒玩過幾次的桌遊，可是那是多人的遊戲。  
書架上的那些小說我都看過了，而且都熟到能背出句子來了。  
說起來，我的書架還蠻空的，有幾層什麼東西都沒有。有時候會想，是不是要再買一些新的書放上去把它填滿。可是不知道為什麼都找不到想放的書。  
這絕對不是我的零用錢都拿去吃甜點了，所以每次去書店錢都不夠！  
<br/>
「對了！」  
趁這個機會把零用錢存起來，之後再跟有里去書店請她推薦一些書好了，它會推薦什麼類型的呢？我猜是本格推理！  
<br/>
所以今天就先什麼都不做，來念書！  
之前為了出去玩都沒什麼念，現在剛好能夠再把進度超前。  
這樣應該不會那麼累吧？  
畢竟今天花的是時間而已。  
<br/>
「咚！」  
在我把書放回書架上時，一本筆記本掉了下來，上面織了一層緊實的灰塵。  
雖然封面已經退色了，可是我還記得那本就是我的日記本。  
感覺很懷念呢，以前會每天寫日記呢！但是那個習慣不知道被我忘記多久就是了。  
而且怎麼看起來那麼舊？只是幾年前的東西而已耶？雖然聽過東西只要不用就會容易壞掉，可是那不是只對電器有用嗎？  
算了，這都不重要，因為我今天又有一件事要做了！  
<br/>
———— 那就是寫日記！
