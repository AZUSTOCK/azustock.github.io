# 「生氣」
我本來想寫一篇長文來罵他，後來想想還是算了。  
還是寫畫畫的東西好了。  
<br/>
這次畫 !![rei] "橘色"足立レイ!! 是最快的一次，我大概下午開始畫，然後去睡覺，再來隔天5點畫到9點。  
不過我睡前就畫完頭髮跟身形了，早上基本上就把細節加完而已。  
不過頭髮真的是要改最久的！  
(絕對不是因為我畫全身才會畫眼睛，兩個都畫超久的)  
不過這次頭髮畫很快，而且脫離了那個「複製」的想法。  
(畫!![miku] "藍色"初音ミク!!的時候就開始有點了呦\~  
<br/>
怎麼講，  
就是有點「就算我畫的跟原本形象不一樣也沒有關係！」的感覺？  
(不過我一直都覺得畫的很可愛的說...)  
<br/>
不過感覺有點開心，  
畫出自己的感覺這件事！  
<br/>
從一張公式圖，把她拆成無數個碎片，然後我再選我想要的部分把她組合起來、把顏色填起來、把自己加一點進去，最後再把她發出去。  
從「真的可以畫出來嗎？」  
到「畫完了！」  
經過了半年。  
雖然我不會用酷酷的筆刷、時髦的調色跟簡潔的線條。  
<br/>
不過就是這種感覺！  
要簡單又不簡單的、要複雜又不複雜的！  
就是這種四不像的才是^^風川梓(わたし)^^呢！
